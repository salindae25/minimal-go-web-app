# Agent guidance

Keep this template focused on reusable UI, theme, and server foundations.

- For Vue component inventory, composition, route views, and Pinia state, read [docs/components.md](docs/components.md) when changing frontend behavior or components.
- For Tailwind utilities, CSS ownership, theme aliases, and palettes, read [docs/ui-conventions.md](docs/ui-conventions.md) when changing styles or themes.
- For Go handlers, SPA fallback, asset caching, configuration, and lifecycle, read [docs/go-conventions.md](docs/go-conventions.md) when changing server code.
- For linting, formatting, builds, and verification, read [docs/tooling.md](docs/tooling.md) when changing code or tool configuration.
- For implementation, refactoring, and review, follow [docs/code-quality.md](docs/code-quality.md), combining `thermo-nuclear-code-quality-review` and [Ponytail](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md) (full mode).
- For module or API interface alternatives, use [.agents/skills/design-an-interface/SKILL.md](.agents/skills/design-an-interface/SKILL.md); it compares distinct designs before implementation.
- For polish or hardening of an existing web artifact, use [.agents/skills/impeccable-design-polish/SKILL.md](.agents/skills/impeccable-design-polish/SKILL.md).
